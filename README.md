# Zomato Logistics Analytics Project

## Project Overview

This project analyzes Zomato delivery operations using
Python and data analytics techniques.

## Objectives

- Analyze delivery performance
- Calculate logistics KPIs
- Identify factors affecting delays
- Build a delay prediction model

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## KPIs

- Average Delivery Time
- Delay Rate
- Orders per Rider
- Average Delivery Distance

## Results

The project identifies operational bottlenecks and
provides insights for improving delivery efficiency.
